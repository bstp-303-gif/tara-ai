# MyGPGD J360 — Demo Guide

A self-contained demo with synthetic data covering **all 16 states and all 143 districts (PPD)**:
about 1,150 fictitious teachers certified by Google, Microsoft and Apple. It runs on its **own database** (`demo/demo.sqlite3`)
and never touches the real (shared) database. Emails are **not sent** — each one is saved as a file in
`demo/sent_emails/`.

## Before the demo

Run these once from the project folder (the last one resets everything, so you can rehearse and re-run it):

```
python manage.py migrate --settings=mygpgd.settings_demo
python manage.py seed_demo --settings=mygpgd.settings_demo
```

Start the demo server (or pick **Demo Server** in Claude's preview list):

```
python manage.py runserver 8001 --settings=mygpgd.settings_demo
```

Open **http://localhost:8001**. Application links for teachers who haven't applied yet are in
`demo/LINKS.md` (regenerated by every `seed_demo`).

## What's already in place after `seed_demo`

- The three certification files are uploaded and processed: **1,283 records → 1,157 unique teachers**,
  126 certified by two providers, 41 not eligible (Google Level 1, Microsoft Office Specialist, Apple
  Professional Learning). One file has a missing email and one a missing year, shown highlighted in red.
- **Every district has teachers**, in varied numbers: most district/track groups have 2 to 5, some have 1,
  and about 1 in 8 has none, so the minimum of 2 per track is not met everywhere (112 groups nationally).
- Invitations were "sent" to most eligible teachers. **3 have not been sent yet** (plus 1 with no email, which is skipped), so you can show the
  Admin approving them.
- **1,108 applications** submitted. **4 invited teachers haven't applied**; their links are in `demo/LINKS.md`.
  One of them is certified by two providers and must choose a technology track.
- The submission deadline is 14 days from today, so applications are still open.
- Last year's group: 139 recognised GPGDs across the country, with about 300 activity reports, for the
  Recognition and Activity dashboards and the monthly reports.
- Report recipients for everyone: the BSTP Director, all 16 State Directors and all 143 PPD leads (demo addresses).

## Suggested walkthrough (about 15 minutes)

1. **Admin: certification data.** Log in as `admin`.
   - **Results / Dashboard**: 3 files, deduplication (1,283 → 1,157), multi-certified teachers, eligible vs not eligible.
   - **Download** the highlighted file to show the cells flagged in red.
2. **Admin: invitations.** In **Review & Approve Invitations**, point out the email status beside each
   name ("Email sent", "Not sent yet", "No email"). Click **Approve & Send Invitations**: 3 invitations go out.
3. **Teacher: receive the email and apply.** Click **Open the Demo Inbox** in the orange bar (or go to
   http://localhost:8001/agents/demo/inbox/). It shows every email the demo has sent, like a mailbox.
   - Search **invitation**, open one of the 3 new invitations, and point out the teacher's name and the deadline.
   - Click the **Apply here** link in the email: the teacher's application form opens, already filled in.
     (Best in a private window, or after logging out, so it looks exactly as a teacher sees it.)
   - Fill in the remaining fields (WhatsApp, school leader, district, LNPT scores and so on) and, in
     **6. Annual National Recognitions**, tick the ones held (with years) or "never received any". Submit.
   - Back in the Demo Inbox, the teacher's **acknowledgement email** is at the top.
   - For a teacher certified by two providers (who must choose a track), use their link in `demo/LINKS.md`.
4. **Show the lock.** **Compile & Rank** is greyed out: *"Applications are still open until …"*.
5. **"The deadline passes".** On the Admin dashboard, set **Submission deadline** to yesterday and click **Save**.
6. **Compile & Rank.** Click it, on the Admin dashboard or as `moe_officer` on **MoE Review**.
   1,109 applications are ranked within each state. About two-thirds are flagged **Recommended**, and
   112 district/track groups are reported below the minimum. The system also checks last year's GPGD
   records: 3 Johor applicants are found there, even if they declared "never recognised".
7. **State Officer.** Log out, then log in as `johor_officer`.
   - **State Review**: the ranked Johor list. Each name shows **★ Never recognised** or the recognitions held.
     Johor has 4 **reserved places**, e.g. PPD Johor Bahru / Microsoft: a Recommended place kept for the
     best-scoring never-recognised teacher, who ranks below others in the state. Approve a few and decline one.
   - Johor's 11 districts show the gaps: e.g. PPD Kluang has no Microsoft applicants and PPD Mersing no Apple
     applicants (highlighted in **By District**, "No applicants yet" in **Statistics**).
   - **Approved & Declined**, **Statistics** (progress and quota per district) and **By District** (click a number to see the names).
8. **MoE Officer.** Log in as `moe_officer`.
   - **Maximum per State** (optional): no maximums are set, so there is no limit. A maximum can be set later
     per state or per district (PPD) and track, for example if a provider asks for one.
   - **MoE Review**: approve a State-approved candidate, with an award category. Their **Letter of
     Recognition** appears in the Demo Inbox.
   - **By District**: the nationwide grid. Pick a state to see its districts.
9. **Admin: after recognition.** **Recognition Dashboard** (map, by state and track) and **Activity Reports**.
   - **Activity Reports** shows the current GPGDs (last year's group in the demo, until you approve someone this year).
     Pick a year to see an earlier group, and **Download Excel** for any year.
   - **Settings → Monthly Reminder**: the reminder text, sent to the current GPGDs on day 15 (3rd week), and the
     day the leaders' statistics go out (day 7, end of the 1st week). Both editable.
   - **Manage → Report Recipients**: BSTP Director, State Directors and District Education Leads (demo addresses
     are filled in for everyone). Click a state for its districts, or fill everyone in from Excel.
   - **Monthly Reports**: pick last month, see the national totals (teachers, students, activities, hours).
   - **AI briefings (Reporting Agent, the second agent)**: click **Prepare briefings**. In about a minute the agent
     reads the national figures, then all 16 states in parallel, and writes a summary with "needs attention" points
     for the BSTP Director and each State Director. Open **How the agent worked** to show its tool calls. Every
     number is checked against the data. Edit if you like, tick, **Save & approve ticked** (human in the loop).
     (Automatically, the agent drafts these two days before the reports go out.)
   - Click the **BSTP** or a **State Director** recipient: the approved summary is at the top of their email.
     Then **Send now**, and open the Demo Inbox to show what each leader receives.
   - Note: the briefings need last year's group (it has the activity reports). Prepare them **before** approving
     anyone this year in the demo, or the current group switches to this year's, which has no reports yet.
   - **Activity report form** (link in any reminder email in `demo/sent_emails/`): participants are now entered as
     teachers, students, school leaders and others.

To start again, stop the server, run `seed_demo` again, and start the server.

## Starting from an empty system instead

To upload the certification files live during the demo:

```
python manage.py seed_demo --fresh --settings=mygpgd.settings_demo
```

This creates only the logins, rules and deadline. Upload the three files in `demo/files/`
(choose the matching provider for each) and click **Process All Files**. To then "fast-forward" so most
invited teachers have applied, run:

```
python manage.py seed_demo --applications --settings=mygpgd.settings_demo
```

All names, IC numbers, emails and schools in the demo are fictitious.
